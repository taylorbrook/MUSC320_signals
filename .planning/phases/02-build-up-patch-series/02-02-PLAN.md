  <name>Task 2: Create 05-envelopes.maxpat -- line~ and *~ for amplitude shaping</name>
  <files>patches/05-envelopes.maxpat</files>
  <action>
Create a self-contained .maxpat teaching line~ with *~ as an amplitude envelope. This IS Topic 5 (TOPC-05).

**Signal chain:**
cycle~ 330 -> *~ (right inlet from line~) -> live.gain~ -> clip~ stereo -> dac~ + ezdac~

**Envelope control chain:**
toggle -> sel 0 1
- sel outlet 1 (toggle ON) -> message "0, 1. 500" -> line~ (fade in: start at 0, ramp to 1.0 over 500ms)
- sel outlet 0 (toggle OFF) -> message "0 100" -> line~ (fade out: go to 0 over 100ms)
- line~ output -> *~ right inlet (envelope multiplies the tone)

**Envelope format explanation (critical teaching content):**
- "0, 1. 500" means: immediately go to 0, then ramp to 1.0 over 500 milliseconds
- "0 100" means: ramp to 0 over 100 milliseconds
- The comma in "0, 1. 500" separates the immediate-set (0) from the ramp target-time pair (1. 500)

**Visual feedback:**
- live.scope~ #1: tapped at line~ output, showing the envelope shape (ramp up, ramp down)
- live.scope~ #2: tapped at *~ output (after envelope multiplication), showing the shaped tone

**Output chain:** live.gain~ (parameter_longname "Build-05 Vol") -> clip~ stereo -> dac~

  <action>
Create a self-contained .maxpat teaching phasor~ for continuous modulation, +~ for voice mixing, and multi-voice architecture. This is the most complex build-up patch before the final rebuild.

**Voice A: Amplitude-modulated tone (tremolo)**
- phasor~ 0.5 -> cycle~ 0 (phase inlet, right inlet) -> *~ 0.5 -> +~ 0.5 = unipolar LFO (0 to 1)
  This is the standard unipolar LFO pattern from the demo: phasor~ drives cycle~ via phase input, scale to 0-1 range
- cycle~ 330 -> *~ (right inlet from unipolar LFO) = amplitude modulation (tremolo)
  The LFO makes the tone pulse rhythmically

**Voice B: Detuned drone (beating)**
- cycle~ 220 (fundamental)
- cycle~ 223 -> *~ 0.7 (detuned partial, lower amplitude -- matches demo Voice 3 decision)
- Both summed via +~
  The 3 Hz difference creates a gentle beating effect

**Voice mixing:**
- Voice A output and Voice B output summed via +~ before the output chain
- This demonstrates +~ as "signal addition = mixing voices"

**Master level control:**
- toggle -> sel 0 1 -> line~ messages ("0 100" for off, "0, 1. 500" for on) -> line~ -> *~ on the mixed signal
  Reuses Patch 05's envelope concept for master level

**Output chain:** live.gain~ (parameter_longname "Build-06 Vol") -> clip~ stereo -> dac~ + ezdac~

**Visual feedback (3-4 scopes):**
- live.scope~ on LFO signal (unipolar output of +~ 0.5) -- shows the smooth 0-1 cycling

- live.scope~ on mixed output (before live.gain~) -- optional, shows combined signal
